# Jeremiah Diaz — Quality Engineer Portfolio

Responsive, dark-themed personal portfolio website for GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — mobile navigation
- `assets/quality_engineer_header.gif` — animated QA header

## Publish
1. Open `https://github.com/jhdiaz01/jhdiaz01.github.io`.
2. Upload the *contents* of this folder to the repository root (not the folder itself).
3. Commit the files to the `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Wait for deployment, then visit `https://jhdiaz01.github.io`.

## Before publishing
- Replace the LinkedIn placeholder URL in `index.html` with your actual profile.
- Add a resume file and link if desired.
- Replace planned-project cards with links to real repositories when ready.
- Review skills and experience statements for accuracy.
- Never add employer-confidential code, credentials, customer data, or proprietary documentation.

## Custom domain
After the site works on GitHub Pages, configure `jeremiahdiaz.com` in **Repository Settings → Pages** and add the DNS records GitHub specifies at your registrar. Keep the verification TXT record in place as instructed by GitHub. Enable HTTPS once available.

This is a static site and requires no build step or paid hosting. Google Fonts load remotely, with system-font fallbacks.
